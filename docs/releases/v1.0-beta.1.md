# OpenWrt Installer v1.0-beta.1

`v1.0-beta.1` is the first beta of the minimal OpenWrt x86_64 shell installer.
It embeds OpenWrt 25.12.5 for offline installation and can optionally download
and verify a newer official stable x86/64 image before target selection.

## Highlights

- Three-entry BIOS/UEFI hybrid boot menu with conditional local-disk default.
- Hellforge `whiptail` interface with keyboard and local-console mouse input.
- Guided LAN, WAN, PPPoE, static IPv4, and WAN DHCPv6/PD configuration.
- Read-only import of validated OpenWrt backup archives from USB.
- Detection of existing ext4 x86 OpenWrt installations with Safe Upgrade,
  rescue/reinstall, and standard `sysupgrade` handoff choices.
- OpenWrt-compatible, expanded, whole-disk, and custom storage profiles.
- Compatible layout keeps payload partitions 1 and 2 exact, creates an ext4
  data partition on 80% of the remaining space, and leaves a 20% SSD reserve.
- Persistent compatible-layout `sysupgrade` guard and UUID-based data mounts.

## Validation Scope

The release artifact is validated by the repository smoke suite, BIOS/UEFI
QEMU installation and boot tests, local-disk boot tests, the QEMU mouse matrix,
storage profile and recovery tests, two guarded standard upgrade cycles, Safe
Upgrade, USB configuration import, and AHCI/NVMe virtual-device coverage.

The ISO was also booted on the VMware test machine and navigated through target
selection, existing-install actions, and storage profiles without writing the
disk.

The schema 4 physical SATA/NVMe storage, recovery, and power-cycle report is
not complete for this build. This beta is therefore not a bare-metal storage
certification. Use a backup and a non-essential target disk.

## Files

- `openwrt-x86-64-installer-hybrid.iso`: recommended BIOS/UEFI boot media.
- `openwrt-x86-64-installer.img.gz`: raw live-installer disk image.
- `openwrt-x86-64-target.img.gz`: embedded OpenWrt target payload.
- `manifest.json`: payload identity and clean-build provenance.
- `sha256sums.txt`: checksums for all published artifacts.
